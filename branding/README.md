# AsterionCore Branding

This directory contains the canonical branding assets for AsterionCore.

Every future branding modification must use these files as the single source of truth.

## Primary Reference

AsterionCore-Branding-Board.png

The branding board defines:

- logo
- launcher icon
- adaptive icon
- monochrome icon
- notification icon
- splash screen
- official colors
- visual language

Do not redesign the logo from scratch.

Future refinements must preserve:

- circular composition
- Möbius strip geometry
- Ouroboros symbolism
- premium proportions
- brushed metallic gold
- subtle engraved dragon scales
- polished black onyx eye
- luxury appearance

The logo should always remain elegant and restrained.

Avoid fantasy styling.

The dragon should remain subtle and secondary to the Möbius strip.

The application should always use the official black-and-gold theme defined by the branding board.{\rtf1}
